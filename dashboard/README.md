# dashboard/

Next.js app for the AI Social Media Manager. See the [root README](../README.md) for the
workflow and commands; run everything from the workspace root (`npm run dev`, `npm run submit`, …).

```
app/          page + API routes (thin; all logic is in lib/)
components/   sidebar, calendar, overview, queue, post drawer
lib/          blotato client, store, scheduler, publish orchestration, time helpers
scripts/      CLIs: submit, queue, sync, accounts
```

`CLAUDE.md` / `AGENTS.md` in this folder are generated by `next dev` and point at the Next.js
version-specific docs in `node_modules/next/dist/docs/`.
